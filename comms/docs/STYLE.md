# Docs & writing style

Governs written reports/summaries Claude or Hermes hand to Oliver — not a
new voice, mostly a pointer to the one already set in `CLAUDE.md`:

- Terse. No emojis. No `---` dividers. No marketing language.
- Evidence over assumption; state results directly, no hedging filler.
- Headers only where they earn their keep — a two-paragraph note doesn't
  need a heading hierarchy.

## What this file adds

**Sender mark.** A doc identifies who produced it by which mark it uses,
not a shared logo — `assets/claude-mark.svg` for Claude, `hermes-mark.svg`
for Hermes, `hop-mark.svg` / `finance-mark.svg` for the finance identities.
Use it small (e.g. a 20-24px inline image next to a title), never as a
full-bleed header graphic — these are working docs, not marketing pages.

## Cadence for AgentMail identities

Four inboxes exist today: `claude@n3wth.com`, `hermes@n3wth.com`,
`hop@n3wth.com` ("hop Finance"), `finance@n3wth.com` ("n3wth Finance").
Whichever inbox sends, its mark is the one that appears — don't substitute
a different identity's mark for convenience.
